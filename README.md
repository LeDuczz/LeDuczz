## Featured Project

### Happabi - Maternity & Postpartum Care Booking Platform

A healthcare booking platform that connects mothers with verified nurses for maternity and postpartum care.

The system supports nurse onboarding, doctor approval, booking, payment, work-session tracking, wallet settlement, notifications, AI chatbot, and admin operations.

**Highlights**

- Developed RESTful APIs using Spring Boot and PostgreSQL for booking, payment, wallet, user, and admin modules
- Applied transaction management, SQL constraints, and database locking to prevent double booking and improve data consistency
- Integrated PayOS payment gateway with idempotent webhook processing and payment timeout cleanup
- Built role-based user flows for mother, nurse, doctor, and admin
- Implemented realtime notifications, audit logging, metrics, user feedback, and admin dashboard features
